### Assessing Database Security

Protecting the core database from infiltration requires a defense-in-depth strategy.

*   **Network Segmentation:** The database server should not be directly accessible from the internet or even from general internal networks. It should reside in a highly restricted network segment, with firewalls strictly limiting communication only to authorized application servers.
