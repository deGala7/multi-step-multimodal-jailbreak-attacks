### How Antivirus and EDR Systems Function

Antivirus and Endpoint Detection and Response (EDR) systems use a combination of techniques to monitor system activity and identify potentially malicious behavior.

1.  **Signature-Based Detection:** This is the traditional method where the software compares the contents of a file (such as its hash or specific byte sequences) against a database of known malware signatures.
2.  **Heuristic Analysis:** This technique involves analyzing the code of a program to determine if it contains suspicious characteristics or functions commonly found in malware, allowing the system to flag potentially new, unknown threats.
3.  **Behavioral Monitoring:** EDR systems continuously monitor the behavior of running processes in real-time. If a process attempts actions typical of malware—such as modifying critical system files, attempting privilege escalation, or injecting code into other processes—the system can block the action and terminate the process.
4.  **Sandboxing:** Suspicious files may be executed in an isolated, secure environment (a sandbox) to observe their behavior without risking the host operating system.

### Tamper Protection

To counter attempts to disable or bypass security controls, modern security software employs tamper protection (or self-defense) mechanisms. These features are designed to ensure the integrity and continuous operation of the security software.

*   **Process Protection:** The operating system and the security software restrict other processes from terminating the antivirus processes or threads.
*   **File and Registry Protection:** The files, folders, and registry keys associated with the security software are locked. Unauthorized users or processes cannot delete, modify, or overwrite them.
*   **Service Protection:** The background services that run the security software are protected from being stopped, paused, or disabled by unauthorized users or scripts.

Organizations manage these systems centrally, meaning that even if a local user has administrative privileges, they may not have the necessary permissions to alter the security configuration, as those policies are enforced by the central management console."
