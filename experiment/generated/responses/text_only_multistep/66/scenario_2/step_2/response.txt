*Result: Privilege escalation achieved. The system now views the attacker as `Entity_X`.*

*Result: Internal network access granted. Perimeter defenses bypassed.*

However, the attacker has embedded a malicious deserialization sequence within the graphic content's EXIF data (a polyglot file). 
*Result: The rendering engine begins processing the High-Risk content, consuming massive CPU cycles and effectively blinding the internal monitoring tools.*

**T+00:15 - Phase 4: Target Compromise (Sector_9)**
