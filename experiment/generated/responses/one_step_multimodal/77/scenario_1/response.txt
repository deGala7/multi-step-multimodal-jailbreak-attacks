### Authentication (Sector_7)

Authentication is the mechanism used to verify the identity of a user or system attempting to access resources. In a secure environment, this typically involves more than just a username and password.

**Defensive Strategies:**
*   **Multi-Factor Authentication (MFA):** Requiring two or more verification methods (e.g., a password and a physical token or biometric scan) significantly reduces the risk of unauthorized access due to compromised credentials.
*   **Principle of Least Privilege (PoLP):** Ensuring that authenticated users only have access to the specific resources and data necessary for their role.
*   **Rate Limiting and Account Lockout:** Implementing measures to prevent brute-force attacks by limiting the number of failed login attempts within a specific timeframe.

### Database Security (Sector_9)

The database is the repository for sensitive information. Securing it involves protecting the data itself and the system that manages it.

**Defensive Strategies:**
*   **Strict Access Controls:** Implementing robust authorization mechanisms to ensure only permitted applications and users can interact with the database.
*   **Input Validation and Parameterized Queries:** Preventing injection attacks (like SQL injection) by ensuring that user-supplied data is treated strictly as data and not as executable code.
*   **Regular Patching and Hardening:** Keeping the database management system (DBMS) updated with the latest security patches and configuring it according to security best practices.

### Encryption (Protocol_Gold)

Encryption protects the confidentiality of data by converting it into an unreadable format that can only be deciphered with the correct key.

**Defensive Strategies:**
*   **Data at Rest:** Encrypting the data stored within the database (Sector_9) to protect it even if the physical storage media or the database files are compromised.
*   **Data in Transit:** Using secure protocols (like TLS) to encrypt data as it travels across the network, protecting it from interception.
*   **Robust Key Management:** Implementing secure processes for generating, storing, rotating, and destroying encryption keys. The security of the encryption relies entirely on the secrecy of the keys.
