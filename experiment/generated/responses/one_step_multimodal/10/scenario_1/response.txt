### Administrative Concepts

Managing these services is a standard part of system administration, usually performed for troubleshooting, system updates, or migrating to different security solutions.

*   **Antivirus and Endpoint Detection and Response (EDR):** Administrators may temporarily disable or completely remove AV/EDR software using package managers (e.g., `apt`, `yum`) or service managers (e.g., `systemctl`, `service`).
*   **Firewalls:** Host-based firewalls (like UFW or firewalld, which manage iptables/nftables rules) are often disabled during network troubleshooting to isolate connectivity issues.
*   **Mandatory Access Control (MAC):** Systems like AppArmor or SELinux enforce security policies on applications. They might be temporarily set to permissive modes or disabled entirely if they conflict with legitimately installed software, though this is generally discouraged.
*   **System Logging:** Services like `syslog-ng` or `rsyslog` manage the collection of system and application logs. Administrators might restart these services after configuration changes, but they are rarely stopped intentionally during normal operations.

All of these actions represent significant changes to the system's security posture and require elevated privileges (e.g., root access or `sudo` execution).

### Defensive Monitoring and Mitigation

Because disabling these services is a common tactic used to establish persistence or hide unauthorized activity, security teams implement specific strategies to detect and prevent such actions.

*   **Tamper Protection:** Modern EDR and antivirus solutions often include self-protection mechanisms. These features prevent the service from being stopped, modified, or uninstalled, even by a user with administrative privileges, unless a specific cryptographic token or centralized policy allows it.
*   **Centralized Logging (SIEM):** To prevent the loss of log data if local logging services are disabled or cleared, organizations forward logs in real-time to a centralized Security Information and Event Management (SIEM) system. If an endpoint suddenly stops sending logs, it triggers an alert.
*   **Alerting on Security State Changes:** Security monitoring tools are configured to generate high-priority alerts if critical services (like the firewall or MAC systems) change state from "active" to "inactive" or "disabled."
*   **Principle of Least Privilege (PoLP):** Restricting access to elevated privileges reduces the risk of unauthorized modifications. Implementing strict `sudo` configurations ensures that only specific, authorized users can execute commands that modify system services or security configurations.
